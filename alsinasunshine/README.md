# Alsina Sunshine — Official Music Artist Website

Official website and discography showcase for **Alsina Sunshine**, a premier Sierra Leonean recording artist, songwriter, singer, and prolific performing artist blending R&B, Hip-Hop, and Afrobeats Pop at a world-class professional standard.

## Featured Singles & Discography

- **Freetown Nights** — *Afrobeats Pop*
- **Salone Pride** — *Cultural Afrobeats / Anthem*
- **Sunshine Riddim** — *Afro-Dancehall & Pop*
- **Sweet Melody** — *R&B / Soulful Pop*

## Tech Stack & Architecture

- **HTML5**: Semantic markup, Open Graph metadata, accessible landmarks, and descriptive ARIA tags.
- **CSS3**: Custom design system with CSS custom properties, responsive Flexbox & CSS Grid, smooth gradients, and scroll animations.
- **Vanilla JavaScript**: Lightweight client logic handling sticky navigation, mobile menu drawer, scroll reveals, active navigation observers, and an interactive Web Audio preview player. No heavy dependencies or duplicate frameworks.
- **Assets**: High-resolution track cover artworks and artist profile photography.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser, or serve with a local server (e.g. `npx serve .` or VS Code Live Server).

## Customization & Booking

- **Booking & Management Email:** Update `alsinasunshine.booking@gmail.com` in `index.html`.
- **Streaming Platforms:** Links for Spotify, Apple Music, Audiomack, YouTube, and Instagram can be customized in the `#music` and `#contact` sections.
- **Brand Colors:** Tailor palette tokens (sunshine gold, secondary accents, and dark background values) in `:root` of `css/style.css`.
